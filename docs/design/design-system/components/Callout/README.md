# Callout

Callout is an inline notice inside a page — staleness, hints, validation results.

**Props:** `tone` — `info` (default) | `success` | `warning` | `danger`; `title`; `children`; `action` — an optional element (usually a sm Button) on the right.

- The stale-lesson banner is a `warning` Callout at the top of the lesson: "The code has changed since this lesson — 2 files differ."
- Always a filled icon + text; never only a coloured stripe or left border.
