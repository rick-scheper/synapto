# Badge

Badge labels a lesson, concept or state in a compact chip.

**Props:** `tone` — `neutral` (default) | `accent` | `success` | `warning` | `danger`; `children` — short text (1–3 words).

- `accent` for concepts ("octree", "spatial hashing"); `neutral` for metadata (difficulty, repo).
- Status tones prepend ✓ / ! / ✕ automatically so state is never colour-only.
- Don't use badges as buttons.
