# Logos

- `synapto-logo-lockup.png` — neuron mark above the SYNAPTO wordmark. Splash, README header, empty Library.
- `synapto-mark.png` — the mark alone (256×256). Favicon, top bar, app icon.
- `synapto-wordmark.png` — the wordmark alone.
- `synapto-logo-original.png` — the full source artwork (1408×768).

All are rasters on the logo's navy ground (≈ `surface` dark, #18202a–#29333f); none has a transparent background. Use them on dark grounds only; in the Light theme place the mark on a `#18202a` tile with `radius-md`. A vector/transparent version is still needed.
