What happens to a point at x = -0.2 with a voxel size of 0.5 if voxel_key used astype(int) instead of np.floor?

Pick one, then check your answer.

{{o.text}}
{{verdict}} Spatial hashing

Casting to int truncates toward zero, so -0.4 becomes 0 and the point joins the cell [0, 0.5) on the positive side. Floor keeps every cell the same half-open interval [k·size, (k+1)·size), so -0.2 correctly lands in cell -1.
